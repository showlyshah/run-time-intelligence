# MyMoney — Android expense tracker

Standalone Android application project. Minimum Android version: 8.0 (API 26). Debug APK is built by the GitHub Actions workflow at `.github/workflows/mymoney-apk.yml`.

## MVP
- Offline income and expense entry using SQLite
- Transaction history and balance summary
- Daily, weekly, monthly and yearly expense filters
- Category spending pie chart
- Android 8.0+ support target

Budgets, account management and custom category editing are planned follow-up work; the current screens are placeholders.
